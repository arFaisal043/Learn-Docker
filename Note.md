- Docker Image:
A blueprint/template for creating containers. Think of it like a class in programming.

- Docker Container:
A Docker container is a standardized, lightweight, and isolated runtime environment that packages an application and its dependencies. It's a running instance of a Docker image.


🐳 What is Docker Hub? 
Think of Docker Hub as "GitHub for Docker images" - it's a cloud-based registry where you can find, store, and share container images.

The Simple Analogy 📚
Service:	                      Purpose:
GitHub	                          Store and share code
npm	                              Store and share Node.js packages
Docker Hub	                      Store and share Docker images
